# 🌸 Emily Brand Guidelines — Unified System (UI + Presentation + Data)

This system separates color usage into 3 clear domains:

1. **UI System (Product / App)**
2. **Presentation System (Slides / Decks)**
3. **Data Visualization System (Charts / Graphs)**

> [!IMPORTANT]
> ❗ Never mix these systems directly. Each has a different purpose.

---

# 🌿 1. UI SYSTEM (Product / Dashboard)

## Base Colors

- Primary Text: `#1A2332`
- Secondary Text: `#8B8680`
- Background: `#FAF8F3`
- Card: `#FFFFFF`

## Surface Variants

- Whisper Cream: `#FDFCFA`
- Soft White: `#FEFEFE`

## Accent (Semantic)

| Type       | Main      | Pastel     |
|------------|----------|------------|
| Active     | #D4AF37  | #F8F3E8    |
| Positive   | #2C5F8D  | #E3EBF2    |
| Milestone  | #B76E79  | #F2E8EB    |
| Alert      | #C87E6C  | #F5EDE9    |

## Rules

- Pastel = background only
- Main color = text / icon / border
- Never use accent colors as large background blocks

---

# 🎤 2. PRESENTATION SYSTEM (Slides)

## Base

- Slide Background: `#FAF8F3`
- Content Block: `#FFFFFF`

## Text

- Primary: `#1A2332`
- Secondary (adjusted for readability): `#6F6A65`

## Accent Usage

- Use **only 1–2 accent colors per slide**
- Prefer:
  - Sapphire `#2C5F8D`
  - Terracotta `#C87E6C`

## Optional Highlight

- Soft Gold (refined): `#C9A227`

## Rules

- Avoid pastel in text-heavy slides
- Avoid mixing all 4 semantic colors together
- Keep slides calm → focus on hierarchy, not color variety

---

# 📊 3. DATA VISUALIZATION SYSTEM (Charts / Graphs)

## Core Data Palette

Use for bar / line / pie:
`#2C5F8D`  (Primary)
`#C87E6C`
`#B76E79`
`#C9A227`
## Extended Palette
For large datasets:
`#5A6C7D`
`#8A7C8F`
`#A39B94`

## Forbidden

- ❌ All pastel colors
- ❌ Background colors
- ❌ Mixing semantic meaning into categories

## Chart Styling

### Background
- Chart BG: `#FFFFFF`
- Slide BG: `#FAF8F3`

### Grid / Axis
- Grid: `#E8E6E4`
- Axis Text: `#6F6A65`

### Bar Chart
- Border: none
- Radius: 4–6px

### Line Chart
- Thickness: 2–3px
- Point color = line color

---

# 🎯 4. DATA STORYTELLING RULE

## Highlight Pattern

- Default data = muted tones
- Key insight = Sapphire `#2C5F8D`

Example:
Normal data → gray / muted

Important → blue
## Purpose

- Guide attention
- Reduce cognitive load
- Improve clarity instantly

---

# 🧠 5. SEMANTIC vs DATA (CRITICAL RULE)

## Semantic (UI only)

- Success = Blue
- Alert = Terracotta
- Milestone = Rose

## Data (Charts only)

- Colors = categories only
- NO meaning attached

> [!IMPORTANT]
> ❗ Do not reuse semantic meaning in charts

---

# 🧩 6. USAGE RATIO

## UI

- 80% Neutral
- 15% Pastel
- 5% Accent

## Presentation

- 85% Neutral
- 10% Accent
- 5% Highlight

## Data

- 90% Data colors
- 10% Highlight

---

# ✨ 7. SYSTEM PHILOSOPHY

- UI → Soft, layered, emotional
- Presentation → Clear, structured, calm
- Data → High contrast, readable, decisive

# 🌸 FINAL NOTE

This system is designed to maintain:
- Visual elegance (Emily brand)
- Functional clarity (real usage)
- Cross-platform consistency (UI → Slides → Data)

> [!NOTE]
> Beauty supports clarity — not the other way around.
